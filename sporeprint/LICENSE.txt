## WHY THREE LICENSES

Each license covers a different dimension of the same work:
- AGPL protects the CODE that implements the design
- ORC protects the DESIGN ITSELF (irrevocable, perpetual)
- CC-BY-SA protects the DOCUMENTATION that explains it

If you only use one license, there's a gap — and that gap is
where enclosure happens. scyBorg closes every gap.
