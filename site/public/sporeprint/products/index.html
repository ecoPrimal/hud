    Products

    Emergent compositions of primals — what happens when standalone tools combine to do real work. Not commercial software; chemical reaction products.

    “Product” here means chemical reaction product — what emerges when you combine primals. These are not commercial software for sale. helixVision is what happens when barraCuda (math) + coralReef (compiler) + toadStool (dispatch) + NestGate (storage) are composed and pointed at genomic data. You get sovereign protein structure prediction — an emergent capability that no single primal provides alone.

    Products come from two organizations:

    • sporeGarden — infrastructure compositions and established products that consume primals via JSON-RPC
    • protoKarya — protists: wider-world compositions evolving toward external usability. The first living things.

    Infrastructure (sporeGarden)

    • 🧫🔗 cellMembrane — sovereign VPS control plane, K-Derm relay management
    • ⚛️🚀 projectNUCLEUS — deployment and composition layer (TOML deploy graphs)
    • 🏛️🌱 projectFOUNDATION — institutional adoption bridge
    • 🪨🌱 lithoSpore — self-verifying scientific deployment: USB-deployable validation artifacts that carry the science, the data, the tools, and the provenance chain. First instance: LTEE reproduction (75/75 checks, 7 modules)

    See also: Ecosystem Inventory for the complete repository map, and Deployment Model for how products consume primals via 🧬📦 plasmidBin.

    • blueFish — Sovereign Data Pipeline Sovereign ETL and data pipeline — NCBI integration, format conversion, no cloud lock-in.
    • coralForge — Sovereign Structure Prediction Engine Pure Rust f64 AlphaFold2/3 primitives validated against NumPy — the substrate for helixVision's sovereign protein structure prediction.
    • esotericWebb — Cross-Evolution CRPG A CRPG that composes primals via JSON-RPC — the first proof that sovereign infrastructure produces real games.
    • footPrint — GIS Home Planner Sovereign GIS home planning tool — the first protoKarya protist. Static SPA live at primals.eco/footprint/, with 10 GIS upstream sources via drawbridge proxy.
    • helixVision — Self-Hosted Structure Prediction Protein structure prediction pipeline in pure Rust f64 — no cloud, no PyTorch, no CUDA, no data leaves the lab. Primitives validated; end-to-end pipeline in progress.
    • initioChem — Interactive Computational Chemistry An interactive free energy landscape explorer — the first gen4 product where computational chemistry infrastructure becomes invisible to the researcher.
    • lithoSpore — Targeted GuideStone Deployment USB-deployable, self-verifying scientific validation artifacts. The first instance reproduces the Long-Term Evolution Experiment (LTEE) targeting the Barrick Lab at UT Austin.
    • nautilus — Neuromorphic Reservoir Computing Adaptive intelligence through evolutionary BingoCube reservoirs, ESN integration, and heterogeneous brain architecture on sovereign hardware.
    • NF Case Study — First Multi-Product Composition for External Science Neurofibromatosis data mining as the gen5 proof case: multiple products composing to serve an external scientist's question, where the deliverable is her science.
    • Sovereign Lattice QCD — Pure Rust Gauge Theory on Consumer GPUs Lattice QCD physics engine in pure Rust + WGSL — 59/59 checks, 3 published papers reproduced, guideStone-certified. Product packaging in development.
    • tideGlass — Sovereign GPS Platform Sovereign GPS data analysis platform — reproducing published GPS methodology in pure Rust. Phase 0: reproduce GPS paper figures vs Python baseline. Second protoKarya protist.
