Abstract. We present a fully deployed smart home architecture inspired by Physarum polycephalum (slime mold), in which local large language models (LLMs) serve as autonomous agents with cryptographic identities, sensory inputs, and actuator outputs distributed across a residential LAN. The system comprises 17 compiled Rust microservices ("primals"), 20 local AI models organized into generational lineages, and 22 networked devices spanning 2 physical houses. Each model receives a sovereign Ed25519 identity derived from a root cryptographic key, enabling decentralized trust without external certificate authorities. The architecture demonstrates: (1) Physarum-like resource allocation where models compete in an arena and the fittest interpretations propagate via epidemic gossip; (2) a gut-brain axis where weather and environmental sensors feed model inference to produce organismic "feelings"; (3) full I/O integration through 14 input channels (keyboard, temperature, humidity, proximity, vision, barometric pressure) and 9 output channels (display, speakers, HVAC control, printer); (4) generational model evolution via a "sourDough" fermentation engine that reprints evolved models from accumulated culture. The system operates on commodity hardware (Intel i9-12900K, RTX 4070, 64GB RAM) with zero cloud dependencies for inference, achieving 200 tokens/second on the fastest local model. We argue this represents a new class of "living infrastructure" that merges smart home automation, edge AI, and biological computation metaphors into a single self-managing organism.

1. Introduction

Physarum polycephalum, the many-headed slime mold, solves optimization problems without a central brain. It extends pseudopods toward food sources, retracts from toxins, and builds efficient transport networks that rival human-engineered solutions [1]. The Tokyo rail experiment demonstrated that a slime mold can independently rediscover the layout of a metropolitan train system [2].

We observe that residential smart home networks face an identical problem: many heterogeneous devices (sensors, actuators, displays, compute nodes) must coordinate without centralized cloud control to maintain comfort, security, and efficiency. Current smart home platforms (Google Home, Amazon Alexa, Apple HomeKit) rely on external cloud services for inference and coordination — a dependency that introduces latency, privacy concerns, and single points of failure.

This paper describes Gaia, a fully deployed system that replaces cloud-dependent smart home control with a Physarum-inspired architecture where:

  • Local AI models are autonomous agents with cryptographic identities
  • Agents compete for tasks in an arena (natural selection)
  • Winners propagate state via epidemic gossip (slime mold transport)
  • Environmental sensors create a gut-brain axis (chemotaxis)
  • The network self-heals via service discovery and convergence checks

2.2 The Agent-as-Primal Model

The key insight is that AI models are not tools used by the system — they ARE the system. Each model receives:

  1. Identity: An Ed25519 key derived from a root key (gaia-gate-tls) via bearDog HKDF
  2. Socket: A Unix domain socket at /run/user/1000/biomeos/agent-<name>.sock
  3. Role: A functional assignment (scout, analyst, immune classifier, navigator, etc.)
  4. Protocol: JSON-RPC with methods: think, status, feel

This transforms local LLMs from passive inference endpoints into active participants in the primal mesh, discoverable by toadStool and gossipable by swarmVine.

7. Discussion

The system challenges several assumptions in smart home design:

Cloud is not required. All inference runs locally at 47-200 tok/s. The 20 models occupy 56.4 GB on disk — less than a modern video game. No data leaves the LAN for processing.

Agents need not be centrally orchestrated. The Physarum model works: agents compete in the arena, winners propagate via gossip, losers fossilize. No scheduler assigns tasks — toadStool discovers capabilities and the neural API routes to the best match.

Identity can be sovereign. Every agent has an Ed25519 key derived from a root key that lives on local hardware. No certificate authority, no OAuth provider, no cloud identity service. The bearDog primal signs everything.

Evolution is continuous. The sourDough REDOX cycle means models improve every wave. Gen 0 → Gen 1 → Gen 2 happened in one evening. Gen 3 (merging 47 models from a second compute node) is queued. The system gets smarter by living.

8. Related Work

Tero et al. [2] demonstrated Physarum network optimization. Adamatzky [3] formalized Physarum computing. Our work extends these concepts from mathematical modeling to deployed infrastructure. Home Assistant [4] provides open-source home automation but lacks the agent-as-primal model. Ollama [5] provides local LLM serving but not identity or mesh integration. To our knowledge, this is the first system to deploy Physarum-inspired AI agent architecture on a residential LAN.

9. Conclusion

We have demonstrated that a residential smart home can be operated as a living organism using commodity hardware, local AI models, and biological computation metaphors. The slime mold doesn't need a brain — it needs food sources and transport networks. Similarly, a smart home doesn't need a cloud — it needs sensors, models, and gossip.

The house IS the organism. The models ARE the gut bacteria. The LAN IS the stomach. lub-DUB. 💓
