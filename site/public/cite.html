?? how to get a real DOI (Zenodo)

Zenodo  run by CERN. Free. No endorsement.

Zenodo gives you a real DOI (Digital Object Identifier) that works in any citation system. It integrates directly with GitHub and ORCID.

  1. Go to zenodo.org ? Sign in with GitHub
  2. Connect your GitHub account (ecoPrimal org)
  3. Toggle ON the repository you want to publish (sporePrint, or the thesis)
  4. Create a GitHub Release (e.g., v1.0.0-thesis)
  5. Zenodo automatically archives it and assigns a DOI
  6. DOI looks like: 10.5281/zenodo.XXXXXXX
  7. Link the DOI to your ORCID profile

Then every citation with that DOI is tracked globally. Google Scholar indexes it. Semantic Scholar indexes it. Every reference manager imports it. The academic system HAS to see you.

?? ORCID setup

ORCID  your persistent researcher identity

  1. Go to orcid.org/register
  2. Create your profile (free, permanent, yours)
  3. You get an ORCID iD like: 0000-000X-XXXX-XXXX
  4. Add your works:
    • The Zenodo DOI (auto-imports if linked)
    • GitHub repos as "Software"
    • The sporePrint as "Working Paper"
    • Each spring as "Dataset"
  5. Add to EVERY profile:

    • LinkedIn
    • Steam profile (yes, really)
    • primals.eco

The ORCID iD IS the backscatter frequency. Every profile that carries it bounces back to the same source. The citation IS the endorsement.
