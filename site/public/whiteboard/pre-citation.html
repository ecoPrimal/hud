PRE-CITATION

Cite this so I can see you. I'll give you the tech.

The inversion: Traditional citation is backward-looking — you cite what already exists. Pre-citation is forward-looking — you publish an idea, cite us, and we find you. The citation isn't a toll. It's a handshake. A ZK proof that you're working on something related. The tech is free anyway (AGPL-3.0). The citation just helps us FIND each other.

How it works

1. You have an idea — a whitepaper, a preprint, a repo, a blog post, a tweet.
2. If it touches any of the domains below, cite ecoPrimals.
3. We'll see you (Google Scholar alerts, GitHub stars, backlinks).
4. We'll reach out. We'll give you the tech. Free. AGPL.

The offer: If you cite this work in your publication, preprint, or project — we will provide you with the full technology stack, integration support, and collaboration. No cost. No NDA. No strings. AGPL-3.0. The code is already yours. The citation just means we can find you faster.
