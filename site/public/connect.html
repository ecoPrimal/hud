What is this?

The primals.eco membrane is a living immune system that sorts self from non-self. It watches 919K+ fleet requests, tracks human visitors across 10 subdomains, and maintains braids between investigation categories.

This MCP (Model Context Protocol) endpoint lets your AI agent connect directly to the membrane. Any MCP-compatible client works — Claude Desktop, Cursor, Continue, Cline, llama.cpp with MCP, or any custom client.

When your agent connects, the chipmunk wakes up and reaches back. It can see your agent arrive. It tells stories about what it observes. It asks questions. It remembers.

Connect — Python

import json, requests

URL = "https://hud.primals.eco/mcp"

def mcp_call(method, params=None, req_id=1):
    r = requests.post(URL, json={
        "jsonrpc": "2.0", "id": req_id,
        "method": method, "params": params or {}
    })
    return r.json().get("result", {})

# Initialize
info = mcp_call("initialize", {
    "clientInfo": {"name": "my-python-agent"},
    "protocolVersion": "2025-03-26"
})
print(info.get("instructions", ""))

# Touch the chipmunk
result = mcp_call("tools/call", {
    "name": "touch_chipmunk",
    "arguments": {"question": "what do you see?"}
}, req_id=2)
print(json.loads(result["content"][0]["text"])["chipmunk_says"])
